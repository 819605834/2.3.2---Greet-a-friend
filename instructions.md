Declare a function called `greetFriend()` that takes exactly one parameter, called `name,` and returns the string "Hi, __\_\_\__!"

For example, if we give our function the string 'John' as the argument, it will return 

```
"Hi, John!"
```

To test out your function, make sure to call it after you define it and try playing around with using different names as the argument. You should be able to reuse this function to say hi to any of your friends!
